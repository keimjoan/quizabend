Eigene Boards

Ein Board hat fünf Kategorien mit je fünf Fragen von 100 bis 500 Punkten. Schreib es selbst in der Vorlage für Excel oder Google Sheets, oder lass es dir von Claude schreiben. Danach importierst du es mit einem Klick ins Spiel. Eigene Boards werden zuerst gespielt.

2So füllst du die Vorlage aus

Im Blatt Board steht eine Zeile pro Frage, also 25 Zeilen für ein Board. Die Kopfzeile bleibt, wie sie ist.

BoardKategoriePunkteFrageAntwort
Geburtstag LisaLisa privat100In welcher Stadt ist Lisa aufgewachsen?Bremen
200Wie heißt Lisas Katze?Mimi
… bis 500 Punkte, dann die nächste Kategorie …
Unsere Urlaube100Auf welcher Insel waren wir 2019?Mallorca
… insgesamt fünf Kategorien mit je fünf Fragen
  • Board und Kategorie nur in die erste Zeile schreiben. Leere Zellen darunter gehören zur selben Kategorie bzw. zum selben Board.
  • Punkte 100, 200, 300, 400, 500: von leicht nach schwer. Die Reihenfolge der Zeilen ist egal, das Spiel sortiert selbst.
  • Antworten kurz halten. Andere Schreibweisen in Klammern dahinter, zum Beispiel „Der Pazifik (Pazifischer Ozean)“.
  • Mehrere Boards in einer Datei: weitere 25 Zeilen darunter, mit neuem Board-Namen in der ersten Zeile. Sie werden in dieser Reihenfolge gespielt.
  • Statt Excel geht auch eine CSV-Datei mit denselben Spalten (Komma, Semikolon oder Tabulator).

3Boards von Claude schreiben lassen

Claude-Skill

Skill „quizabend-board“

Der Skill bringt Claude bei, wie ein gutes Board aussieht: fünf Kategorien, steigende Schwierigkeit, eindeutige Antworten mit Varianten in Klammern. Claude liefert eine JSON-Datei, die du direkt importierst.

Claude-Skill (.zip)

Skill einrichten

  1. In Claude (Web oder App): In den Einstellungen bei Fähigkeiten den Bereich Skills öffnen, „Skill hochladen“ wählen und die ZIP-Datei auswählen. Je nach Version heißen die Menüpunkte etwas anders.

  2. In Claude Code: Die ZIP-Datei in den Ordner ~/.claude/skills/ entpacken, sodass dort quizabend-board/SKILL.md liegt.

  3. Danach einfach im Chat nach einem Board fragen. Claude nimmt den Skill von selbst.

Zum Beispiel so fragen

Schreib mir zwei Quizabend-Boards zum Thema 90er-Jahre, für eine Runde Erwachsener. Ein Board eher leicht, eins schwer.

Mach ein Quizabend-Board für den 40. Geburtstag von Tom. Hier ein paar Fakten über ihn: …

Bei persönlichen Themen brauchst du Claude die Fakten zu geben, sonst müsste es raten. Prüf die Fragen vor dem Spielabend kurz durch.

4Board ins Spiel holen

  1. Öffne das Spiel. Auf der Startseite steht der Bereich Eigene Boards, im Online-Spiel in der Lobby beim Gastgeber.

  2. Klicke auf Board importieren und wähle die Datei: Excel (.xlsx), CSV oder die JSON-Datei von Claude. Oder markiere die Zellen in Excel bzw. Google Sheets samt Kopfzeile, kopiere sie und füge sie ins Feld ein.

  3. Klicke auf Importieren. Fehlt etwas, sagt das Spiel genau, wo, zum Beispiel „Kategorie Sport, 300 Punkte: Die Antwort fehlt“.

  4. Ausgewählte eigene Boards werden zuerst gespielt. Mit „Boards“ unten auf der Seite stellst du ein, ob danach noch zufällige Boards aus den eingebauten Kategorien kommen.

Eigene Boards werden nur in deinem Browser gespeichert. Auf einem anderen Gerät importierst du sie einfach noch einmal. Im Online-Spiel reicht es, wenn der Gastgeber das Board hat: Die Mitspieler sehen die Fragen automatisch.

5Tipps für gute Fragen

  • 100 Punkte weiß fast jeder, 500 nur Kenner. Eine gleichmäßige Steigerung macht das Spiel spannend.
  • Jede Frage hat genau eine richtige Antwort. Kurze Antworten (ein Begriff, ein Name, eine Zahl) lassen sich leicht bewerten.
  • Fragen so schreiben, dass man sie gut vorlesen kann. Die Antwort sollte nicht schon in der Frage stecken.
  • Kategorienamen kurz halten, damit sie auf der Tafel gut lesbar sind.
  • Mit dem KI-Spielleiter im Online-Spiel helfen Varianten in Klammern, damit auch „Pazifik“ für „Der Pazifische Ozean“ zählt.

6Für Fortgeschrittene: JSON-Format

Das Spiel liest auch dieses Format, zum Beispiel aus eigenen Skripten. Jedes Board braucht genau fünf Kategorien, jede Kategorie genau fünf Fragen.

{
  "boards": [
    {
      "name": "Name des Boards",
      "kategorien": [
        {
          "name": "Kategorie 1",
          "fragen": [
            { "punkte": 100, "frage": "Leichte Frage?", "antwort": "Antwort" },
            { "punkte": 200, "frage": "…", "antwort": "…" },
            { "punkte": 300, "frage": "…", "antwort": "…" },
            { "punkte": 400, "frage": "…", "antwort": "…" },
            { "punkte": 500, "frage": "Schwere Frage?", "antwort": "Antwort" }
          ]
        }
      ]
    }
  ]
}

Einzelne Kategorien statt ganzer Boards importierst du auf der Startseite über „Eigene Fragen schreiben“. Die landen dann im Topf, aus dem die Boards zufällig gezogen werden.
